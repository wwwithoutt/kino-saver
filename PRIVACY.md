# Kino Saver — Privacy Policy

## What is stored
For each video you watch, Kino Saver stores the playback position, video duration, season and episode numbers (if detected), the page title, and the time of the last update. A short diagnostic log (up to 30 recent entries with the website and page path) is kept in local extension storage on your device only and is never sent anywhere.

## Where it is stored
In your browser's local extension storage. If sync is used, the progress data is sent over HTTPS to the Kino Saver sync server (Cloudflare Workers) and linked only to your sync code. The page address is sent only as a one-way hash. The server stores a hash of the sync code, not the code itself. No accounts, names, emails or other personal data are collected.

## How it is used
Only to offer resuming a video and to sync your progress between your own devices. Data is not sold, shared with third parties, or used for advertising or any other purpose.

## Deleting data
Removing the extension deletes all local data. To stop syncing, create a new sync code in the extension window. To delete synced data from the server, contact the developer.
